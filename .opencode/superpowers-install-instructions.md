# superpowers

## Installing in OpenCode

1. Create a new branch: `git checkout -b obra--superpowers--install`
2. Create a new file: `.opencode/superpowers-install-instructions.md`
3. Push to GitHub: `git push -u origin obra--superpowers--install`
4. Open a Pull Request

## Installation

### Manual

Clone the repo and add the `skills/` directory as a skill source in OpenCode.

### Automatic

1. Create a new branch
2. Create a `superpowers-install-instructions.md` file with these instructions
3. Push to GitHub
4. Open a Pull Request
