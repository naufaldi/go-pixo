The JavaScript decoder is emitted as its own unmodified file, loaded separately from Go Pixo application code, and only when the browser has no native HEIC decoder. To rebuild with a modified library, obtain the Go Pixo source, replace web/node_modules/heic-to/src/lib/libheif-without-unsafe-eval.js (imported by web/src/interop/codecs.ts) with your modified build, build the Go WASM, and run bun run build in web/. This regenerates bundled assets and offline integrity hashes; serve the resulting web/dist directory locally.
