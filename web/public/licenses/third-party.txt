The JavaScript/WASM decoder is loaded separately from Go Pixo application code. Library source and build scripts are available at the links above. To rebuild with a modified library, obtain the Go Pixo source, replace libheif-js with a local modified package in web/package.json, install dependencies, build the Go WASM, and run bun run build in web/. This regenerates bundled assets and offline integrity hashes; serve the resulting web/dist directory locally.
